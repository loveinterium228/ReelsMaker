# Third-party components and media

The MIT license in this repository covers the application source. It does not replace the licenses of dependencies, model weights, fonts, FFmpeg distributions or media assets.

| Component | Reference |
| --- | --- |
| PyQt5 / Qt | [Riverbank license information](https://www.riverbankcomputing.com/software/pyqt/intro) |
| QtAwesome and its icon fonts | [QtAwesome project and bundled font notices](https://github.com/spyder-ide/qtawesome) |
| faster-whisper | [Project license](https://github.com/SYSTRAN/faster-whisper/blob/master/LICENSE) |
| PyAV | [Project repository and license](https://github.com/PyAV-Org/PyAV) |
| FFmpeg | [FFmpeg legal and license information](https://ffmpeg.org/legal.html) |

Whisper models are downloaded separately. Consult the chosen model's repository and notices when redistributing weights.

The eight background clips in `resources/presets/` were present in the supplied project. They were renamed for the English interface; their content is unchanged. Their origin and redistribution permissions are not documented in the supplied files. Confirm the permissions or replace them with owned/licensed clips before distributing them as portfolio assets or in a public release. Personal clips can be added through Background library.

The README screenshots were captured from the application with a synthetic demonstration graphic created for this review. They do not use the bundled background clips.
